# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub:

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability**.

Please don't open a public issue for a security problem.

## Scope

In scope:

- the scripts, tutorials and Terraform modules in this repository;
- the permissions they grant;
- anything that could make them send more data than they show you.

## What this repository never does

- It never asks for, stores or sends cloud keys, passwords or tokens.
- It never grants more than the roles listed in its documentation for the
  release you run.
